# Current data gaps

2026-11-23 — supersedes previous static-only / spectator substitution status.

- Six exact-code portraits have been generated using recovered game1.0.3 resources and the CharacterPortrait pipeline in GDRE Godot4.8-dev. Visual checks and input/output hashes passed; live Steam-game imports remain untested.
- Portraits show the complete configured accessories in a single front view. Account ownership and hidden/back-facing surfaces are not verified. The actual game can remove unowned accessories when wearing a look.
- The helper engine differs from the installed game's stated engine version. No claim of pixel-identical material/lighting behaviour in every release/environment is made.
- Original community authors remain unidentified where the listing only reports @community. Source screenshots are not used as current character images.
- Packaged spectator PNGs are a separate archive, not a stand-in for player appearances. Runtime cached player pictures are not mapped to these six codes and are not used to illustrate them.
- Controls/guides use first-party package sources but gameplay timing, all build variants, hidden maps/editor-only drills and current online server behaviour are not exhaustively tested.
- Current Steam player count, prices, promotions and Demo access cannot be established from package files. Live requests retain timestamps and unavailable states.
- No deployment, remote repository change, DNS or mailbox setup was performed.
